Privacy

Crash reports

If the game breaks, it sends an anonymous technical report: what went wrong, the game version, the kind of device and browser, and the last few game actions. No name, IP address or account is stored, and nothing you type is sent. Reports are deleted after 90 days.

You can turn this off in Settings → Privacy → Send crash reports.

Online play

When you play online, the game's own server holds the room: the names players typed, a random player number for each player (so you get your own seat back) and the game itself. While a match is being played it's kept in the server's own storage, so a server restart doesn't lose it. It's deleted when the match ends, when the host goes back to the lobby, or after 7 days without a move (24 hours, if nobody has made a move yet and nobody is there). The lobby and a finished game are only held in the server's memory, and cleared at most 5 minutes after everyone has left. None of it is saved anywhere else. (Cloudflare keeps its own recovery copy of the server's storage for up to 30 days, then it's gone.) The server also writes short notes such as "Sam joined", with the room code, which Cloudflare (who runs the server) keeps for a few days so problems can be fixed. No account, email or address book is ever asked for.

Your name, a random player number and the last room's code stay on this device, so the name box is filled in and you can get back into a match. Clearing the site's data in your browser removes them.

Submitted words

A word you send from Pause → Submit a word goes on a list for review, with the day it was sent. Who sent it isn't stored.
